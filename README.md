🌿 Green Land

Green Land is a front-end e-commerce project, created with the aim of providing an intuitive and enjoyable online shopping experience. The platform serves as an interactive demo where users can explore a range of products that include cosmetics, clothing and household items.


✨ Key Features

🛒 Product catalog page, organized by categories

🛍️ Basic shopping cart functionality (add/remove products)

🛠️ Technologies used

HTML5 for the structure of the application

CSS3 for responsive styling and layout

JavaScript (ES6) for interactivity and dynamic logic on the page

🎯 Project Goal

This project is built as a practical exercise in front-end web development, demonstrating skills in:

creating a modern and clean UI,
🔗 Live Demo -("https://green-land.onrender.com")

managing interactions with vanilla JavaScript,

building a page that simulates the process of an online store.
